# Quality of Life

Small, open-source utilities that make everyday computer use easier. Each project can be built and used independently.

| Project | Purpose | Platforms |
| --- | --- | --- |
| [DesktopKeys](projects/DesktopKeys) | Switch Windows virtual desktops with PgUp and PgDn; starts at sign-in and runs without a tray icon | Windows 10/11 |
| [LiteNetMonitor](projects/LiteNetMonitor) | Compact live network speeds, graphs, and session totals | Windows, macOS, Linux |

## Downloads

Get packaged apps from [Releases](https://github.com/yananai-chiwuta/Quality-of-Life/releases). DesktopKeys releases use `desktopkeys-v*` tags. Existing LiteNetMonitor `v*` releases and assets are preserved.

## Build and contribute

See each project README for requirements and commands. Read [CONTRIBUTING.md](CONTRIBUTING.md) for repository conventions and [docs/architecture.md](docs/architecture.md) for layout and release details.
